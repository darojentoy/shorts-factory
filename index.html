shorts-factory

유튜브 쇼츠 제작·예약 게시 도구 (개인용)

이 앱은 무엇인가

shorts-factory 는 운영자 한 사람이 자기 유튜브 채널에 쓰려고 만든 Windows PC 프로그램입니다. 공공 통계와 자체 계산 결과를 그림으로 만들어 짧은 세로 영상(쇼츠)을 제작하고, 운영자가 승인한 영상만 운영자 본인의 채널에 예약 게시합니다.

하는 일

  • 운영자가 승인한 영상과 썸네일을 운영자 본인의 유튜브 채널에 비공개로 올리고 공개 시각을 예약합니다.
  • 올린 영상의 처리 상태를 확인합니다.
  • 운영자 본인 채널의 조회수·시청 지속률 같은 통계를 읽어 다음 영상 기획에 참고합니다.

구글 계정 정보를 쓰는 범위

이 앱은 YouTube API 서비스를 사용하며, 운영자 본인이 구글 로그인 화면에서 직접 허락한 범위에서만 동작합니다. 다른 사람의 계정이나 채널에는 접근하지 않고, 일반 사용자에게 배포하지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.

English summary

shorts-factory is a personal desktop tool. It uploads and schedules videos approved by its single operator to the operator's own YouTube channel and reads that channel's analytics, using YouTube API Services. It is not distributed to other users. See the Privacy Policy.
