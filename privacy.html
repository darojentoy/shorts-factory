shorts-factory 개인정보처리방침

시행일: 2026-11-19 · 앱 소개로 돌아가기

1. 이 앱과 사용자

shorts-factory 는 운영자 한 사람이 자기 유튜브 채널에 쓰는 개인용 PC 프로그램입니다. 구글 계정으로 이 앱에 로그인하는 사람은 운영자 본인뿐이며, 일반 사용자의 가입이나 로그인을 받지 않습니다.

2. 접근하는 구글 사용자 데이터

이 앱은 YouTube API 서비스를 사용합니다. 운영자가 구글 동의 화면에서 허락한 아래 범위에만 접근합니다.

허락 범위접근하는 데이터쓰는 목적
youtube.upload운영자 채널에 올리는 영상·썸네일과 그 제목·설명·공개 설정영상 업로드와 예약 공개
youtube.readonly운영자 채널과 영상의 기본 정보·처리 상태업로드가 제대로 되었는지 확인
yt-analytics.readonly운영자 채널의 조회수·시청 지속률 등 통계다음 영상 기획 참고

영상 삭제, 채널 설정 변경, 댓글 관리, 시청자 개인을 식별하는 정보에는 접근하지 않습니다.

3. 저장하는 곳과 기간

  • 구글이 발급한 접근 허가(토큰)는 운영자 PC 의 Windows 자격 증명 관리자에만 저장합니다.
  • 영상 상태와 통계 수치는 운영자 PC 안의 데이터 파일에만 저장합니다.
  • 이 앱은 별도의 서버를 두지 않으며, 위 데이터를 PC 밖으로 내보내지 않습니다.
  • 통계 수치는 받은 날부터 30일 안에 새로 받아 고치거나 지웁니다. 운영자가 앱 사용을 그만두면 저장된 데이터와 토큰을 모두 지웁니다.

4. 제3자 제공

구글 사용자 데이터를 제3자에게 팔거나 넘기거나 공유하지 않습니다. 광고 목적으로 쓰지 않으며, 인공지능 모델의 학습에 쓰지 않습니다.

5. 허락을 거두는 방법

운영자는 언제든 구글 계정의 보안 설정에서 이 앱의 접근 권한을 끊을 수 있습니다. 끊으면 앱은 더 이상 채널에 접근하지 못합니다.

6. 관련 약관

이 앱은 YouTube API 서비스를 사용하므로 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. 이 앱이 구글 API 로 받은 정보를 쓰는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

English summary

shorts-factory is a personal desktop tool used only by its single operator. It uses YouTube API Services with the scopes youtube.upload, youtube.readonly and yt-analytics.readonly to upload and schedule the operator's own videos and to read the operator's own channel analytics. OAuth tokens are stored only in the Windows Credential Manager on the operator's PC; video status and analytics figures are stored only in local files on that PC. No server is used and no Google user data is sold, transferred or shared with third parties, used for advertising, or used to train AI models. Access can be revoked at any time at myaccount.google.com/permissions. The YouTube Terms of Service and the Google Privacy Policy also apply. Contact: darojentoy@gmail.com
